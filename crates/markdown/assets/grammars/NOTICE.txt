TextMate grammars used to colour code, as bundled by Shiki 4.6.0 (@shikijs/langs, from
tm-grammars 1.32). Each file is the grammar object that package exports, unchanged.
The tokenizer in crates/markdown/src/textmate is a port of vscode-textmate 10.1 (@shikijs/vscode-textmate).

css, go, html, javascript, json, jsx, markdown, python, rust, shellscript, sql, tsx, typescript
  Source: https://github.com/microsoft/vscode (extensions/*/syntaxes), MIT License below.
toml
  Source: https://github.com/textmate/toml.tmbundle (Syntaxes/TOML.tmLanguage)
yaml
  Source: https://github.com/textmate/yaml.tmbundle (Syntaxes/YAML.tmLanguage)
